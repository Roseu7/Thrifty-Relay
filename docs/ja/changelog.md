# 更新履歴

主な変更は[Keep a Changelog 1.1.0](https://keepachangelog.com/ja/1.1.0/)の分類で記載します。
リリースはセマンティックバージョニングに従います。
1.0.0より前は、マイナーリリースでもMCPツールの入出力、設定キー、環境変数、CLIコマンドを旧形式を残さずに変更することがあります。
その場合はChangedかRemovedに記載します。
OSごとの確認状況は[既知の制限](security.md#既知の制限)にあります。
